# Lamba TV apps, a Claude Code plugin

The lamba-tv-app skill: how to build, check, test and upload an app for Lamba TV, the calm screen in a family living room, with the phones in the room. It holds the steps, code patterns for the TV page and the phone page, and the checklist a person at Lamba reviews with.

Use it inside a Lamba app's folder, best the starter kit (https://lamba.tv/devs/kit/starter.zip), which also has lamba-check.mjs and lamba-test.mjs. Connect the Lamba MCP server with a key from https://lamba.tv/devs/keys so the agent can check, upload and follow review. Every step: https://lamba.tv/devs/docs/ai/

## Install

```
/plugin marketplace add https://lamba.tv/devs/claude/marketplace.json
/plugin install lamba-tv@lamba
```
